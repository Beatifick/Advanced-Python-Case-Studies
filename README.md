TMDB Movie Data Analysis

Учебный проект по анализу данных о фильмах на основе датасета TMDB 5000. Включает исследовательский анализ (EDA), визуализацию данных, корреляционный анализ и проверку статистических гипотез. Цель проекта — выявить факторы, связанные с кассовыми сборами, бюджетом и зрительскими оценками фильмов.

Инструменты: Python, Pandas, NumPy, Matplotlib, Seaborn, SciPy.
